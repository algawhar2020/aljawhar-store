# متجر الجوهر | AL JAWHAR — موقع المتجر

موقع ثابت (HTML/CSS/JS فقط، بدون سيرفر). الطلبات تُرسل إلى واتساب صاحب المتجر.

## تغيير أي إعداد (رقم الواتساب، الأسعار، الشحن، الروابط، المنتجات)
كل الإعدادات في ملف واحد: **`config.js`** — افتحه بأي محرر نصوص، عدّل القيمة، واحفظ.

- **رقم الواتساب:** غيّر `whatsappNumber: "966500000000"` إلى رقمك بالصيغة الدولية بدون + وبدون الصفر الأول.
  مثال: 0551234567 ← `"966551234567"`
- **الأسعار:** داخل كل منتج `sizes: [ { label: "30 مل", price: 59 }, { label: "100 مل", price: 89 } ]`
- **الشحن:** `shippingFee` (رسوم الشحن)، `freeShippingThreshold` (حد الشحن المجاني، 0 لإيقافه)، `deliveryDays`
- **إنستقرام/تيك توك:** `instagramUrl`, `tiktokUrl`
- **صور حقيقية:** ضع الصورة في `assets/img/` وغيّر `image:` للمنتج (مثلاً `"assets/img/oud.jpg"`)، ويفضّل صورة عمودية بنسبة 5:6 بخلفية فاتحة.

إذا كان الموقع منشوراً على GitHub Pages: افتح الملف `config.js` في المستودع ← أيقونة القلم (Edit) ← عدّل ← Commit changes. يتحدث الموقع خلال دقيقة تقريباً.

## بعد النشر (لمعاينة الرابط في واتساب)
شغّل مرة واحدة: `python3 set_site_url.py https://رابط-موقعك` ليصبح رابط صورة المشاركة (og:image) رابطاً كاملاً.

## الملفات
- `index.html` الصفحة · `config.js` الإعدادات · `assets/style.css` التصميم · `assets/app.js` منطق السلة والطلب
- `assets/img/*.svg` رسومات الزجاجات · `assets/og-image.jpg` صورة المشاركة · `favicon.ico`, `assets/*.png` الأيقونات
